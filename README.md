# AcousticMonster

Reproducible research code for a Bayesian "sovereign" acoustic-localisation model
on synthetic pulse-echo data and the GPLA-12 gas-pipeline-leakage dataset.
All reported numbers are regenerated by a single driver (`experiments/run_all.py`)
and summarised in `results/SUMMARY.md`.

## Layout

| path | contents |
|---|---|
| `src/` | library: physics, signal core, synthetic generator, sovereign model, training |
| `experiments/` | one script per experiment (E1..E7), plus `common.py`, `run_all.py`, `reporting.py` |
| `scripts/` | `fetch_gpla12.py`, `make_release`, `scan_secrets.py` |
| `results/` | committed tables/figures + `MANIFEST.json`, `SUMMARY.md`, `PROGRESS.md` |
| `tests/` | pytest suite (config, crypto, filters, physics, synth, training, safety, run-all) |
| `data/` | `SOURCE.md`, `DATA_CARD.md` (datasets are downloaded/generated, not committed) |

## Install

Python 3.12.

```bash
python -m venv .venv
. .venv/Scripts/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt # pinned direct deps (lock file: requirements.lock.txt)
```

## Data

* **Synthetic splits** (used by E1, E3, E4, E7):

  ```bash
  python -m src.synth.build_all   # -> data/synthetic/*.npz
  ```

* **GPLA-12** (used by E5), pinned and sha256-verified:

  ```bash
  python scripts/fetch_gpla12.py            # download at commit afec271
  python scripts/fetch_gpla12.py --check    # verify existing files only
  ```

## Reproduce

```bash
python experiments/run_all.py --quick   # ~35 s smoke test -> results/tmp/quick/
python experiments/run_all.py --full    # ~9 min, regenerates results/E1..E7/
python experiments/reporting.py         # rebuild MANIFEST.json + SUMMARY.md
python -m pytest -q                     # full test suite
```

Individual experiments can also be run directly, e.g.
`python experiments/e4_calibration.py`.

### Experiment map and typical runtimes (`--full`, 8 threads, 16 GB RAM)

| id | script | outputs | ~time |
|---|---|---|---|
| E1 | `e1_sos_sensitivity.py` | speed-of-sound sensitivity table + heat-map | 19 s |
| E2 | `e2_stability.py` -> `e2_agreement.py` | divergence table + agreement/figure | 10 s |
| E3 | `e3_echo_snr.py` | delay RMSE vs echo SNR (+denoising ablation) | 41 s |
| E4 | `e4_calibration.py` | sovereign calibration, SNR bins, coverage | 7 min |
| E5 | `e5_robustness.py` | GPLA-12 numerical-robustness report | 35 s |
| E6 | `e6_safety_security.py` | safety truth table + security cases | <1 s |
| E7 | `e7_performance.py` | training throughput / inference latency | 31 s |

E3 and E4 keep their pre-audit / pre-normalisation versions as labelled
ablations (`results/E3/e3_table_v1.csv`, `results/E4/e4_metrics_v1.csv`).

## Release

```bash
python scripts/make_release              # release/acousticmonster-v1.0-paper.zip + tag
python scripts/scan_secrets.py           # value-aware secret scan of tracked files
```

`make_release` archives **tracked files only** (models, datasets, `.env` and git
history are excluded by construction), then secret-scans the zip and aborts if
anything is found.
